## 🎵 GaanaaSpot

GaanaaSpot is a simple and clean Spotify Clone built using HTML and CSS.
It recreates the look and feel of Spotify’s UI with a focus on layout, design, and responsiveness.

<img width="1912" height="975" alt="image" src="https://github.com/user-attachments/assets/beced259-410b-4664-bb4b-0a63e3f721f0" />


🚀 Features

🎧 Spotify-style modern UI

📁 Sidebar navigation layout

🎼 Song cards and playlists section

🖼️ Clean and responsive design

🎨 Fully built with pure HTML + CSS (no frameworks)

📂 Project Structure<br/>
GaanaaSpot/<br/>
├── index.html<br/>
├── style.css<br/>
└── assets/   # images, icons, songs <br/>

🛠️ Built With

HTML5

CSS3

📄 About

GaanaaSpot is a front-end practice project inspired by Spotify’s interface, created to enhance UI design and CSS layout skills.
